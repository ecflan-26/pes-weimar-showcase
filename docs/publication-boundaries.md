# Publication boundaries

This repository is a fresh allowlisted showcase. No original Git history or bulk production archive is copied.

Included: newly written documentation, dependency-free demo and synthetic exercises.

Excluded: customer/learner names, messages, invoices, bookings, contact exports, recommendation letters, job applications, private analytics, screenshots of account consoles, keys, tokens, provider account identifiers, production form endpoints and original third-party assets.

Future changes should use fictional names and example.com addresses. Never add .env files, database dumps or receipts. Keep deployment credentials in the hosting service rather than in code. Do not turn the private job engine or production workspace public.

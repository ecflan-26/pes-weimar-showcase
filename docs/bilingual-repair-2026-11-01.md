# Toolkit 1.1.0 release — 1 November 2026

The separate paid Gumroad delivery now contains version 1.1.0. The superseded pilot buyer ZIP was removed from its content, the saved listing survived reload, and a fresh download matched SHA-256 `cdc9b14c543c39c6b59aa1014a58a5578c34b1844e97da701abcdfb09dce1b51`. This verifies delivered bytes, not a customer purchase or revenue. The EUR199 price and five-company pilot cap were preserved.

The tools use explicit application labels and structured generated strings. User names, notes, CSV data cells, storage keys and JSON schemas stay unchanged. The release includes 411 UI dictionary entries, 124 translated template sentences, English/German interfaces and matching four-page PDF/Markdown buyer guides.

A portable Windows x64 local launcher now serves only toolkit assets at a fixed loopback address. The official Node.js runtime was checked against its published archive checksum; its complete third-party licence is included privately with the buyer package. Start/Stop are on demand, with no installation, administrator rights, internet dependency or startup task. Browser data still requires JSON backups and the same browser profile/address. The server has no customer-record API.

Tests on the extracted buyer package passed: 223 Call Prep assertions, 36 recovery/syntax assertions, 846 localisation/preservation assertions and 24 launcher checks. All four actual JSON backups restored into an empty isolated copy and survived reload. All four tool states remained after complete launcher stop/restart. Native Chrome opened all four tools; a rating, draft and checklist metadata survived reload. All 12 measured 390/768/1280 viewport combinations had no page-level overflow. All eight PDF pages were rendered and visually inspected.

The earlier native URL-confidence block was resolved after the owner opened a recognised address; it was not bypassed. Direct file:// persistence was never certified and is retained only as a legacy mode. The supported Windows launcher is the tested saving workflow. Physical phones, other operating systems, native cross-browser combinations and real customer migrations are not certified. In-app clipboard readback was inconclusive; TXT export is verified.

Skywork was the principal original developer; Earl provided business direction, professional expertise and review; Codex performed later repairs, localisation, verification and guide production. Full paid source, runtime binaries, customer records and confidential data are excluded from this public repository.

## Storage and recovery

Saved toolkit data remains in browser localStorage, without encryption or cloud synchronization. Use the same browser profile and supported local address, and keep versioned JSON backups. All four actual JSON backups restored into an empty isolated copy; all four tool states survived launcher stop/restart in the released-package checks.

CSV/TXT exports are separate from the tested JSON recovery path. Real customer migrations, other operating systems, physical phones and native cross-browser combinations are not certified. Direct `file://` saving is legacy and unverified; the supported saving workflow is the Windows launcher. The launcher has no customer-record API.

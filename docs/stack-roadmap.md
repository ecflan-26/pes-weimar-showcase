# PES stack direction

Use the service website as the public front door, the existing enquiry route for intake, one existing factual opportunity tracker for actual enquiry/scope/payment status, and the four-tool workbench for preparation and review. Keep employment applications separate. HubSpot is not an established dependency.

Priorities:

1. Keep one release register with version, archive hash, tested scope, source location and rollback record.
2. Extend structured, tested backup/restore to Evidence Capture, ICP Profiler and Release Checklist.
3. Link evidence, conversations and deliverables using a confirmed engagement reference. Do not assume local-file browser storage is shared across tools.
4. Unify navigation and English/German controls.
5. Track actual enquiry, qualified conversation, written scope, acceptance, payment and delivery separately. Exclude internal QA from business results.

Avoid duplicate CRMs, new paid infrastructure, autonomous outreach or another website rebuild without a demonstrated need. Historical toolkit, written audit and live rehearsal are separate offers. No price or public service scope is changed by this portfolio update.

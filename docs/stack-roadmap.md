# PES stack direction

**Current baseline:** toolkit 1.1.0 was delivered and checksum-verified on 1 November 2026. Bilingual interfaces/guides, structured JSON recovery for all four tools and the portable Windows x64 saving workflow are implemented and tested within the [documented release scope](bilingual-repair-2026-11-01.md).

Use the service website as the public front door, the existing enquiry route for intake, one factual opportunity tracker for actual enquiry/scope/payment status, and the four-tool workbench for preparation and review. Keep employment applications separate. HubSpot is not an established dependency.

## Remaining priorities

1. Maintain one release register with version, archive hash, tested scope, source location and rollback record.
2. Validate real existing-customer migrations before claiming them supported. Keep browser/profile/address requirements and unfinished-draft boundaries explicit; JSON recovery does not imply cloud synchronization.
3. Validate additional operating systems, physical phones and native cross-browser combinations before expanding supported-platform claims. Direct `file://` persistence remains unverified legacy behaviour.
4. Where a real engagement needs it, use a confirmed engagement reference to connect evidence, conversations and deliverables. Do not assume local browser storage is shared across tools or profiles.
5. Record actual enquiry, qualified conversation, written scope, acceptance, payment and delivery separately. Exclude internal QA from business results.

The earlier restore, translation, guide and delivery-verification tasks are completed for the released 1.1.0 scope; they should not remain listed as unfinished work. Earlier development checkpoints remain dated in [workflow improvements](workflow-upgrades.md).

Avoid duplicate CRMs, new paid infrastructure, autonomous outreach or another website rebuild without a demonstrated need. Historical toolkit, written audit and live rehearsal are separate offers. No price or public service scope is changed by this documentation update.
